# 全地形协同机器人视觉模块 —— 物体分类系统

本项目是我参加 **“全地形协同机器人”** 比赛中的视觉处理子系统。该模块独立完成从数据采集到模型部署的全流程，最终通过串口将识别结果发送给主控 Arduino UNO，实现机器人对不同形状物体的智能分拣与响应。

---

## 📌 项目简介

- **比赛任务**：全地形协同机器人需在复杂地形中自主识别并搬运指定物体。视觉模块负责实时检测前方物体的形状类别。
- **核心功能**：识别 **三角柱**、**圆柱**、**正方体** 三种目标物体，并将分类结果通过 UART 串口发送至 Arduino UNO，供决策系统使用。
- **硬件平台**：选用 **MaixCAM‑Pro**（选型原因详见下文）。
- **开发流程**：独立完成数据集采集 → 数据筛选与清洗 → 标注 → 云端训练（MaixHub）→ 模型部署 → 串口通信实现。

---

## 🧠 分类模型

- **模型类型**：图像分类模型（基于 MobileNetV2 轻量架构，量化为 int8，适配边缘设备）。
- **训练平台**：MaixHub 在线训练服务（使用迁移学习，训练轮次 50，批量大小 32）。
- **输出类别**：
  - `0` → `tri_prism`（三角柱）
  - `1` → `cylinder`（圆柱）
  - `2` → `cube`（正方体）
- **模型文件**：
  - `model_275071.cvimodel` —— 编译后的可执行模型文件（KPU 格式）
  - `model_275071.mud` —— 模型元数据描述文件（含类别标签、输入尺寸等）

## 🔧 硬件与通信

| 组件          | 型号/说明                          |
|---------------|-----------------------------------|
| 视觉处理单元  | MaixCAM‑Pro                        |
| 主控          | Arduino UNO                       |
| 通信接口      | UART 串口（TTL 电平，波特率 115200，8N1）|
| 识别结果发送  | 发送类别 ID（0/1/2）及置信度（可选）|

注意：此处接口需要加上电平转换模块实现3.3V-5.0V的跃迁，不然只能单向通信！！！

### ✅ 选用 MaixCAM‑Pro 的原因

- 内置 **KPU** 神经网络加速器，在 300MHz 下推理速度可达 30 FPS，满足实时性需求；
- 与 **MaixHub** 平台深度集成，支持一键训练、编译、部署，极大缩短开发周期；
- 支持 MicroPython 和 C 开发，代码移植方便，社区提供丰富例程；
- 板载 2.4 英寸 LCD 和 DVP 摄像头接口，方便现场调试与结果可视化；
- 功耗低（< 1.5W），适合电池供电的移动机器人场景。

## 📁 数据集制作（）

所有样本数据均由本人独立采集，流程如下：

- **采集**：在赛道的不同光照条件下，以俯视、侧视、斜视多角度拍摄三种物体各 800+ 张，共 2400+ 张原始图片。
- **筛选**：剔除运动模糊、曝光过度、遮挡面积 > 30% 的图像，保留约 1500 张有效样本。
- **标注**：使用 MaixHub 在线标注工具，为每张图片打上对应类别标签，并按 9:1 划分为训练集和验证集。
